Backend Project Brief - PT Swarnadipa Rampai Teknologi

1. Project Overview

Backend system merupakan REST API yang melayani website frontend dan admin panel. Sistem mengelola data produk, inventory/stok, brand, kategori produk. Backend dirancang untuk scalability dan keamanan dengan autentikasi admin yang ketat.

2. Tujuan Sistem

  • Menyediakan REST API untuk pengambilan data produk, kategori, dan brand.
  • Menyediakan API dinamis untuk data inventory/stok real-time.
  • Menyediakan sistem login & autentikasi administrator.
  • Menyediakan admin panel untuk CRUD produk dan inventory.
  • Menyimpan semua data dalam database terstruktur.

3. Teknologi Backend

  • Framework: Laravel 10/11 (PHP)
  • Database: MySQL 8.0+
  • Authentication: Laravel Sanctum (API Tokens)
  • Validation: Laravel Validator
  • File Storage: Local disk atau S3
  • CORS: Laravel CORS middleware
  • API Documentation: Postman/OpenAPI Spec

<?php
use Illuminate\Support\Facades\Route;

use App\Http\Controllers\Api\StockController;

        Route::get('/stock', [AdminStockController::class, 'index']);
        Route::put('/stock/{product_id}', [AdminStockController::class, 'update']);
    });
});

3.5. Controller Example (Product Controller)

<?php
namespace App\Http\Controllers\Api;

use App\Models\Product;
use App\Http\Resources\ProductResource;
use Illuminate\Http\Request;

class ProductController extends Controller
{
    public function index(Request $request)
    {
        $query = Product::with(['brand', 'category', 'inventory']);
        
        if ($request->brand_id) {
            $query->where('brand_id', $request->brand_id);
        }
        if ($request->category_id) {
            $query->where('category_id', $request->category_id);
        }
        
        $products = $query->paginate(20);
        
        return response()->json([
            'success' => true,
            'data' => ProductResource::collection($products),
            'pagination' => [
                'total' => $products->total(),
                'per_page' => $products->perPage(),
                'current_page' => $products->currentPage(),
                'last_page' => $products->lastPage(),
            ]
        ]);
    }
    
    public function show($id)
    {
        try {
            $product = Product::with(['brand', 'category', 'inventory'])->findOrFail($id);
            return response()->json([
                'success' => true,
                'data' => new ProductResource($product)
            ]);
        } catch (ModelNotFoundException $e) {
            return response()->json([
                'success' => false,
                'message' => 'Product not found'
            ], 404);
        }
    }
}

5. REST API Endpoints

PUBLIC ENDPOINTS (No Authentication Required):

# Get all brands
GET /api/v1/brands
Response: { success: true, data: [...] }

# Get all product categories
GET /api/v1/categories
Response: { success: true, data: [...] }

# Get products by brand & category with filter
GET /api/v1/products?brand_id=1&category_id=1
Response: { success: true, data: [products_array] }

# Get single product detail
GET /api/v1/products/{id}
Response: { success: true, data: {...} }

# Get real-time inventory/stock data
GET /api/v1/stock
Response: { success: true, data: [inventory_array] }

ADMIN ENDPOINTS (Requires Authentication):

# Admin login
POST /api/v1/admin/login
Body: { email, password }
Response: { success: true, token: "...", admin: {...} }

# Admin logout
POST /api/v1/admin/logout
Headers: { Authorization: "Bearer {token}" }

# Get all products (admin)
GET /api/v1/admin/products
Headers: { Authorization: "Bearer {token}" }

# Create new product
POST /api/v1/admin/products
Headers: { Authorization: "Bearer {token}" }
Body: { name, sku, brand_id, category_id, description, image, price }

# Update product
PUT /api/v1/admin/products/{id}
Headers: { Authorization: "Bearer {token}" }

# Delete product
DELETE /api/v1/admin/products/{id}
Headers: { Authorization: "Bearer {token}" }

# Update stock/inventory
PUT /api/v1/admin/stock/{product_id}
Headers: { Authorization: "Bearer {token}" }
Body: { stock_status, quantity, updated_date }

6. Database Structure

Table: admins

id (INT, PK)

Table: brands

id (INT, PK)
name (VARCHAR, UNIQUE)

logo_url (VARCHAR, nullable)
created_at (TIMESTAMP)
updated_at (TIMESTAMP)

Table: categories

id (INT, PK)
name (VARCHAR, UNIQUE)
slug (VARCHAR, UNIQUE)
description (TEXT, nullable)
created_at (TIMESTAMP)
updated_at (TIMESTAMP)

Table: products

id (INT, PK)
name (VARCHAR)
sku (VARCHAR, UNIQUE)
brand_id (INT, FK -> brands.id)
category_id (INT, FK -> categories.id)
description (TEXT)
price (DECIMAL, nullable)
image_url (VARCHAR, nullable)
datasheet_url (VARCHAR, nullable)
is_active (BOOLEAN, DEFAULT true)
created_at (TIMESTAMP)
updated_at (TIMESTAMP)

Table: inventory

id (INT, PK)
product_id (INT, FK -> products.id, UNIQUE)
quantity (INT, DEFAULT 0)
stock_status (ENUM: in_stock, low_stock, out_of_stock)
min_quantity (INT, DEFAULT 5)
last_updated (TIMESTAMP)
updated_by (INT, FK -> admins.id, nullable)
created_at (TIMESTAMP)
updated_at (TIMESTAMP)

6.2. Eloquent Model Example (Product Model)

<?php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Product extends Model
{
    protected $fillable = [
        'name', 'sku', 'brand_id', 'category_id',
        'description', 'price', 'image_url', 'datasheet_url', 'is_active'
    ];

    protected $casts = [
        'is_active' => 'boolean',
        'price' => 'decimal:2',
    ];

    public function brand()
    {
        return $this->belongsTo(Brand::class);
    }

    public function category()
    {
        return $this->belongsTo(Category::class);
    }

    public function inventory()
    {
        return $this->hasOne(Inventory::class);
    }

    public function scopeActive($query)
    {
        return $query->where('is_active', true);
    }
}

10. Security Implementation

  • Password hashing menggunakan bcrypt (Laravel Hash facade).
  • Laravel Sanctum untuk API token-based authentication.
  • Input validation menggunakan Laravel Validator rules.
  • Eloquent ORM dengan parameterized queries (prevent SQL injection).
  • CORS middleware untuk allow frontend domain saja.
  • Rate limiting middleware (max 5 login attempts/5 menit) via RateLimiter.
  • Authorization gates & policies untuk akses kontrol.
  • API versioning (/api/v1/) untuk backward compatibility.
  • Action logging via Laravel Events untuk audit trail.
  • HTTPS only (.env: APP_URL harus https).
  • Environment variables tidak boleh di-expose (gunakan .env).
  • Update Laravel & dependencies secara berkala untuk security patches.

10.1. Laravel Middleware Setup

// app/Http/Middleware/EnsureAdminTokenIsValid.php
namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;

class EnsureAdminTokenIsValid
{
    public function handle(Request $request, Closure $next)
    {
        $user = $request->user();
        
        if (!$user || !$user->tokens()->exists()) {
            return response()->json([
                'success' => false,
                'message' => 'Unauthorized'
            ], 401);
        }
        
        return $next($request);
    }
}

// Register in app/Http/Kernel.php
protected $routeMiddleware = [
    'admin.auth' => \App\Http\Middleware\EnsureAdminTokenIsValid::class,
];
