Frontend Project Brief

1. Project Overview

Frontend website berfungsi sebagai tampilan utama yang digunakan oleh pengguna untuk melihat informasi produk. Sistem frontend dirancang menggunakan teknologi web standar agar ringan, mudah diakses, serta kompatibel dengan berbagai browser dan perangkat.

2. Tujuan Sistem

  • Menyediakan tampilan informasi produk kepada pengguna.
  • Menampilkan daftar produk dalam bentuk tabel.
  • Menyediakan halaman informasi tambahan terkait produk.
  • Mengambil data produk secara dinamis dari backend API.

3. Teknologi yang Digunakan

  • HTML
  • CSS
  • JavaScript

4. Struktur Folder Frontend

/assets
   /css
   /images
   /js
   /pdf

/pages

5. Deskripsi Struktur Folder

  • assets/css : berisi file stylesheet untuk tampilan website.
  • assets/images : berisi gambar yang digunakan dalam website.
  • assets/js : berisi file JavaScript untuk interaksi website dan pengambilan data API.
  • assets/pdf : berisi dokumen PDF yang dapat diunduh oleh pengguna.
  • pages : berisi halaman-halaman utama website seperti halaman produk atau halaman informasi lainnya.

6. Alur Pengambilan Data Produk

Frontend mengambil data produk dari backend menggunakan REST API. Data yang diterima akan diproses menggunakan JavaScript dan ditampilkan dalam bentuk tabel pada halaman produk.

7. Frontend Security

  • Menggunakan HTTPS untuk komunikasi data antara client dan server.
  • Tidak menyimpan informasi sensitif pada sisi client.
  • Melakukan sanitasi data sebelum ditampilkan ke halaman HTML.
  • Melakukan validasi input pada form di sisi client.
  • Menggunakan JavaScript untuk menghindari injection pada tampilan data.

8. Output Sistem

  • Website yang menampilkan informasi produk.
  • Halaman produk yang menampilkan data dalam bentuk tabel.
  • Data produk ditampilkan secara dinamis dari backend API.
